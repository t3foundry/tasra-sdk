# Documentation site

Consumer documentation uses Astro Starlight. `publication.json` explicitly lists
reviewed documents, skills and example files. `sync.mjs` rejects links outside
that boundary; new files are not published automatically. Source links go to GitHub.
Private playbooks, evidence and maintenance code are never copied into the site.

```sh
npm ci --prefix site
npm run dev --prefix site
```

Run `npm run build --prefix site` for a checked static artifact in `site/dist`.
This does not deploy it. Search is generated by Pagefind.
