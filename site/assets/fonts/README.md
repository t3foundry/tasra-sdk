# Site fonts

Inter and Geist Mono match Tasra Explorer. These self-hosted variable WOFF2 fonts
come from `@fontsource-variable/inter@5.3.0` and
`@fontsource-variable/geist-mono@5.3.0` (Latin and Latin Extended, normal style,
weights 100–900). Their SIL Open Font Licenses are included alongside the files.
Other scripts use the system fallback. No font service request is needed at runtime.

Sources: https://www.npmjs.com/package/@fontsource-variable/inter
and https://www.npmjs.com/package/@fontsource-variable/geist-mono.
